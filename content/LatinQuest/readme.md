# LatinQuest: Periculum in Pompeiis

A choose-your-own-adventure Latin game for grades 6–8, in the style of the 1980s branching paperbacks.

A modern-day explorer touches a mosaic in the ruins of Pompeii and is pulled back to AD 79. Nobody speaks English, and the only way home is to translate Latin.

## How to play

1. Open `index.html` in a browser (or turn on GitHub Pages for this repo).
2. Enter your name and email.
3. On each page, translate the Latin inscription or dialogue. A wrong answer blows out one of your 3 oil lamps.
4. Choose your next move. The choices are written only in Latin.
5. There are 10 endings. Only one gets you home.

At the end, students get a certificate with their name, email, score and ending. Have them screenshot it and turn it in.

## Files

- `index.html` – the whole game in one file (no build step, no server needed).
